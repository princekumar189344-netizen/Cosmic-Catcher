## Cosmic-Catcher

# Cosmic Catcher

Cosmic Catcher is a small space-themed game that I made using HTML, CSS and JavaScript.

The goal is to catch falling stars and avoid meteors. Stars increase the score, while meteors remove lives. The game lasts for 60 seconds.

---

## How to Play

- Press Start Game to begin.
- Use the Left and Right arrow keys to move.
- You can also use A and D.
- Catch stars to earn points.
- Avoid meteors.
- Try to get the highest score possible.

---

## Features

- 60-second game timer
- Score system
- Three lives
- Falling stars and meteors
- Collision detection
- High-score saving
- Restart button
- Responsive design

---

## Technologies

- HTML
- CSS
- JavaScript
- HTML Canvas
- Local Storage

---

## What I Learned

While making this project, I learned how to use the Canvas API, handle keyboard input, detect collisions and manage a simple game loop.

---

## My Challenge

One of the challenging parts was making the falling objects interact correctly with the player. I also had to make sure the game worked properly when the player reached the edge of the canvas.

---

## What I Am Proud Of

I am proud that I was able to build an interactive game with a score system, lives, timer and high-score feature.
